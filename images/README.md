# Calculator Reference Images

This directory contains reference images used in the GitHub Copilot CLI exercise. These images provide visual context when using Copilot CLI's image input feature (via `@images/filename` syntax).

## Required Images

### 1. `js-calculator.png`
- **Purpose**: Example of a JavaScript calculator interface
- **Used in**: Step 2 - Creating the basic calculator
- **Description**: Should show a basic calculator with buttons for:
  - Numbers (0-9)
  - Basic operations (+, -, *, /)
  - Equals and clear buttons
- **Referenced in**: `.github/steps/2-step.md`

### 2. `calc-basic-operations.png`
- **Purpose**: Example test cases for basic operations
- **Used in**: Step 2 - Creating unit tests
- **Description**: Should show example calculations like:
  - 5 + 3 = 8
  - 10 - 4 = 6
  - 6 * 7 = 42
  - 20 / 4 = 5
- **Referenced in**: `.github/steps/2-step.md`

### 3. `calc-extended-operations.png`
- **Purpose**: Example test cases for advanced operations
- **Used in**: Step 3 - Testing extended functionality
- **Description**: Should show example calculations like modulo, exponentiation, and square root operations
- **Referenced in**: `.github/steps/3-step.md`
